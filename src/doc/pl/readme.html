Easy Audio Converter

Autor: Kazimierz Parzych. Wersja 1.1.3.

Easy Audio Converter konwertuje zaznaczone pliki i foldery bez wychodzenia z Eksploratora Windows. Konwersja działa w tle przy użyciu składnika FFmpeg dołączonego do dodatku.

Korzystanie z dodatku

  1. Otwórz Eksplorator Windows i zaznacz pliki audio lub foldery.
  2. Otwórz menu NVDA, Narzędzia, Easy Audio Converter i wybierz „Konwertuj zaznaczone pliki lub foldery”.
  3. Aby przekonwertować cały bieżący folder, wybierz „Konwertuj bieżący folder”.

Podmenu Narzędzia pozwala także odczytać stan, anulować zadanie, otworzyć okno postępu, aktualizator, ustawienia oraz stronę wsparcia autora.

Postęp konwersji

Po rozpoczęciu zadania otwiera się niemodalne okno postępu. Pokazuje ono bieżący plik, procent i czas bieżącego pliku, postęp całkowity oraz czas od rozpoczęcia zadania. Okno można ukryć bez zatrzymywania konwersji, a następnie otworzyć ponownie z menu NVDA, Narzędzia, Easy Audio Converter.

Wizualne paski nie powodują automatycznej lawiny odczytywanych procentów. Przycisk „Odczytaj stan konwersji” podaje na żądanie najnowszy plik, postęp bieżącego pliku, postęp całkowity i czas.

Przycisk „Anuluj konwersję”, polecenie z menu lub własny skrót zatrzymuje FFmpeg. Niekompletny plik utworzony przez anulowaną operację jest usuwany.

Ustawienia

Otwórz menu NVDA, Ustawienia, Ustawienia, Easy Audio Converter. W tej jednej kategorii znajdują się zakładki „Ustawienia standardowe” i „Ustawienia zaawansowane”. Na pierwszej możesz wybrać format docelowy, jakość, kodek MP3, sposób zapisu, przeszukiwanie podfolderów, zachowanie struktury katalogów, sposób eksportu metadanych oraz automatyczne sprawdzanie aktualizacji.

Po zaznaczeniu opcji „Zapisuj przekonwertowane pliki obok plików źródłowych” każdy wynik trafi obok źródła. W przeciwnym razie wyniki zostaną zapisane w wybranym folderze docelowym.

Pliki źródłowe i istniejące wyniki nigdy nie są nadpisywane. W razie konfliktu dodatek automatycznie tworzy nazwę z numerem.

Podczas konwersji folderu pomijane są pliki, które już mają rozszerzenie formatu docelowego. Przykładowo istniejący MP3 pozostanie bez zmian przy folderowej konwersji WAV do MP3. MP3 zaznaczony bezpośrednio nadal można świadomie przekodować; źródło pozostanie nietknięte, a wynik otrzyma bezpieczną nową nazwę.

Metadane

Lista eksportu metadanych udostępnia trzy tryby:

  • bez kopiowania metadanych źródłowych;
  • kopiowanie wszystkich globalnych metadanych tekstowych;
  • kopiowanie tylko zaznaczonych pól, takich jak tytuł, wykonawca, album, kompozytor, gatunek, data, numer utworu i płyty, komentarz, prawa autorskie, tekst utworu, język lub wydawca.

Okładka jest strumieniem multimedialnym, a nie polem tekstowym, dlatego nie podlega selektorowi metadanych. Niektóre kontenery obsługują mniej pól tekstowych niż inne.

Zaawansowane ustawienia kodeków

Otwórz kategorię „Easy Audio Converter” w Ustawieniach NVDA i wybierz zakładkę „Ustawienia zaawansowane”. Każdy format docelowy ma oddzielny profil. Po włączeniu ustawień można wybrać przepływność, źródłową lub stałą częstotliwość próbkowania, źródłową liczbę kanałów albo mono/stereo, poziom właściwy dla kodeka i głębię bitową PCM.

Poziom kodeka oznacza jakość algorytmu LAME, jakość Vorbis, złożoność Opus albo stopień kompresji FLAC/WavPack — zależnie od formatu. Niepasujące kontrolki są wyłączane. Wartość -1 lub 0, zgodnie z opisem, zachowuje zwykłe ustawienie jakości.

Aktualizacje

Dodatek może sprawdzać oficjalne wydania GitHub podczas uruchamiania NVDA. Automatyczne sprawdzanie można wyłączyć w ustawieniach, a ręczne polecenie jest dostępne w menu Narzędzia i Zdarzeniach wejścia. Żadne dane osobowe nie są wysyłane.

Pobrany pakiet jest sprawdzany pod względem rozmiaru, sumy SHA-256, gdy GitHub ją udostępnia, integralności ZIP, bezpiecznych ścieżek, nazwy dodatku oraz wersji. Następnie zweryfikowany plik otwiera standardowy instalator NVDA, który nadal prosi o potwierdzenie i restart.

Własne skróty klawiszowe

Otwórz menu NVDA, Ustawienia, Zdarzenia wejścia i znajdź kategorię „Easy Audio Converter”. Własny skrót można przypisać do:

  • otwierania ustawień;
  • szybkiej konwersji zaznaczenia;
  • konwersji bieżącego folderu;
  • zmiany formatu docelowego;
  • zmiany jakości;
  • szybkiego wyboru folderu docelowego;
  • otwierania zaawansowanych ustawień kodeków;
  • pokazywania okna postępu;
  • odczytu stanu;
  • anulowania konwersji;
  • sprawdzania aktualizacji;
  • otwierania strony wsparcia.

Obsługiwane formaty docelowe

MP3, WAV, FLAC, Ogg Vorbis, Opus, M4A/AAC, AAC, WMA, ALAC, AIFF, AC-3, E-AC-3, WavPack, MP2, AMR wąskopasmowy i AMR szerokopasmowy.

Dla MP3 można wybrać LAME albo kodek MP3 Windows Media Foundation. Drugi jest opisany jako opcja Fraunhofer/Windows.

Uwagi

  • Jednocześnie może działać jedno zadanie konwersji.
  • Konwersja folderu wymaga potwierdzenia.
  • Pliki WAV mogą mieć rozszerzenie .wav albo .wave.
  • Pliki wideo są akceptowane, jeśli zawierają odczytywalną ścieżkę audio.
  • Nie można konwertować mediów zaszyfrowanych lub zabezpieczonych DRM.
  • Parametry zaawansowane nieobsługiwane przez format są ignorowane lub wyłączone.
  • Przy błędzie ostrzeżenie pokazuje maksymalnie osiem plików i szczegóły FFmpeg, nie nadpisując żadnego istniejącego wyniku.
