Easy Audio Converter

Author: Kazimierz Parzych. Version 1.8.2.

Easy Audio Converter converts selected files and folders without leaving Windows Explorer. Conversion runs in the background using the FFmpeg component included with the add-on.

Using the add-on

  1. Open Windows Explorer and select one or more audio files or folders.
  2. Open NVDA menu, Tools, Easy Audio Converter, and choose “Convert selected files or folders” for immediate conversion with the saved defaults.
  3. Choose “Convert selected files or folders with options” when you want one-time settings or a named profile.
  4. To convert the complete Explorer folder, choose “Convert the current folder”.

The add-on remembers the Explorer focus that was active before NVDA's menu opened. If no selection can be recovered, either selected-items command opens the standard Windows dialog for choosing multiple files. Use “Choose files to convert” or “Choose a folder to convert” when you always want to open the corresponding Windows dialog.

The Tools submenu also reports status, cancels a job, opens the latest results and settings, and opens the progress window, update checker, and author's support page.

One-time options and named profiles

“Convert with options” lets you choose the format, quality, MP3 encoder, destination, folder behavior, metadata, output filename template, source file date preservation, source replacement, and active processing and codec overrides for one job. Enable “Use these settings for future quick conversions” only when you also want to replace the saved defaults.

The dialog includes Audiobook MP3, Podcast Opus, and Archive FLAC profiles. Complete custom profiles can be saved, replaced, deleted, imported, and exported as safe JSON. Profile names and values are validated before they are stored in NVDA's configuration.

“Preserve source file creation and modification dates” assigns both dates from the input file to each completed output. This setting is also stored in custom profiles.

“Replace source files after successful conversion” permanently deletes each source only after its output has been created, checked, optionally verified, and assigned the requested dates. The option is stored in custom profiles, but every job still requires a separate irreversible-action confirmation whose default answer is No. A source remains untouched after an error or cancellation. If the output succeeds but deleting the source fails, the completed output is retained and reported with its full path.

Planning and output names

Before a folder or one-time-options job starts, the add-on can show a plan with file and skipped counts, destination, total duration, input size, approximate output size, free space, and exact source-to-output paths. It warns about lossy-to-lossy conversion and predicted insufficient disk space.

Filename templates support {source}, {title}, {artist}, {album}, {track}, {disc}, {index}, and {format}. Literal template text acts as a prefix or suffix. Invalid characters and reserved Windows names are sanitized automatically.

Conversion progress

A modeless progress window opens when a job starts. It reports the current file, current-file percentage and time, overall percentage, and elapsed job time, and estimated remaining time. The window can be hidden without stopping conversion and reopened from NVDA menu, Tools, Easy Audio Converter.

The visual bars do not generate automatic percentage chatter. Use the “Report conversion status” button in the progress window whenever you want NVDA to speak the newest file and overall progress.

Use “Cancel conversion” in the window, Tools menu, or a custom gesture to stop FFmpeg. An incomplete output created by the canceled operation is removed. “Stop after current file” finishes the active file and then safely stops the job.

By default, additional conversion commands are added to a sequential queue. In the “Processing and notifications” tab, “When another conversion is active” can instead be set to “Run new jobs in separate progress windows”. Each independent job then gets its own converter, progress window, cancellation, and results. The progress and status commands report all active windows; the queue controls affect only the waiting queue. Independent windows can use more CPU and memory, especially when each job also has several parallel file workers.

Automatic speech can occur at progress milestones, for every file, or only when status is requested. After full success, notification can use speech and sound, speech only, sound only, or no completion notification. Errors and cancellation remain announced for safety.

Independent files in one job can be converted in parallel. On the “Processing and notifications” tab, leave “Parallel conversion jobs” at “Automatic (dynamic load balancing)” or choose an explicit count. Automatic mode starts from the available CPU cores and adapts the number of newly scheduled files when CPU or memory load remains high or low. Each file has its own FFmpeg process, so cancellation terminates all active processes and a boundary stop schedules no new files.

For uneven batches, the queue starts the longest or largest files first and weights overall progress by estimated work. When preflight planning is disabled, an ordinary encode without metadata-aware naming, stream copying, or loudness analysis can skip the preliminary input probe. The results report lists separate times for probing, loudness analysis, encoding/output writing, and finalization.

Do not close or restart NVDA while a conversion is running. Use the Cancel button to stop safely; restarting NVDA ends the active conversion.

Conversion results

The results window lists successful outputs, failed sources, and skipped files. Selecting a row shows its complete paths and a friendly error or skip reason. You can copy a plain-text report, open an output folder, or retry only failed source files using the original job settings. Existing outputs remain protected from overwriting.

Settings

Open NVDA menu, Tools, Easy Audio Converter, Settings. This standalone, resizable window contains “Standard settings”, “Advanced settings”, and “Processing and notifications” tabs. OK validates and saves all three tabs; Cancel or Escape discards changes. The add-on no longer adds an item to the main NVDA Preferences list. On the first tab you can select the target format, quality, MP3 encoder, destination behavior, subfolder scanning, folder-structure preservation, metadata mode, and filename template. The third tab contains loudness, artwork and chapter copying, output verification, preflight planning, parallel worker count, the busy-job policy, progress speech, updates, and separate success, error, and cancellation sounds. Every sound can be tested. GPU acceleration is not used because the add-on's exposed codecs encode audio on the CPU; FFmpeg selects the appropriate thread count automatically.

When “Save converted files next to the source files” is enabled, every result is placed beside its source. Otherwise, results are written below the configured destination folder.

A result is never written over its source or an existing destination file. A numbered name is created automatically when necessary. Source files stay untouched unless the explicit replacement option is enabled and confirmed.

When a folder is converted, files already using the target extension are skipped. For example, an existing MP3 is left unchanged during a WAV-to-MP3 folder job. An MP3 selected directly can still be intentionally re-encoded; its source remains untouched by default and the result receives a safe new name.

Original-stream extraction and AAC remuxing

“Extract original audio stream” copies the first audio stream from a video or other media file without re-encoding. Its codec and quality do not change. The add-on automatically chooses an extension such as .aac, .mp3, .opus, .ogg, .flac, .m4a, .wav, or .aiff; an uncommon codec uses the safe .mka container fallback. Video, source metadata, artwork, and chapters are not included; explicit metadata overrides can still add tags when needed.

“Remux AAC to M4A” places the first AAC audio stream in an M4A container without re-encoding. A file whose first audio stream is not AAC, or which has no readable audio, is reported and skipped before conversion. M4A metadata, artwork, and chapters can still follow their normal preservation settings. Neither stream-copy mode uses quality, loudness, resampling, channel, or advanced codec controls.

Metadata

The metadata export list has three modes:

  • do not copy source metadata;
  • copy all global text metadata;
  • copy only checked fields such as title, artist, album, composer, genre, date, track, disc, comment, copyright, lyrics, language, publisher, BPM, description, grouping, compilation, encoder, ISRC, track/disc totals, and sort fields.

Use “Edit metadata overrides...” to enter values that should replace tags for every output in the job or named profile. Empty fields keep the source value. Overrides are applied after the selected metadata mode, so they can also add a tag when source metadata copying is disabled.

Cover artwork is a media stream, not a text field. A separate option can copy it to MP3, M4A/ALAC, and FLAC when supported. Chapter markers also have an independent option.

Loudness and verification

Professional EBU R128 normalization uses two passes: it first measures the complete source, then encodes with those measurements. Presets are Podcast -16 LUFS, Music and streaming -14 LUFS, Broadcast -23 LUFS, and custom LUFS, dBTP, and LRA targets.

Deep verification decodes the complete result and compares its duration with the source. An invalid result is removed and reported as a failure. The Archive FLAC built-in profile enables verification, artwork, and chapter copying.

Audio file information

“Information about the selected audio file” speaks and displays the container, codec, duration, bitrate, channels, sample rate, size, metadata, artwork presence, and chapter count. The report can be copied.

Advanced codec settings

Open NVDA menu, Tools, Easy Audio Converter, Advanced codec settings, or open the main add-on settings window and select the “Advanced settings” tab. Every encoded target has an independent profile. Enable its override and choose any supported bitrate, source or fixed sample rate, source/mono/stereo channels, codec-specific level, and PCM bit depth.

The codec level means LAME algorithm effort, Vorbis quality, Opus complexity, or compression depending on the selected format. FLAC has a separate list from level 0 (fastest) through 12 (strongest and very slow). WavPack provides named fast, normal, high -h, very high -hh, -hhx1 through -hhx4, and maximum -hhx6 profiles. The corresponding validated FFmpeg levels range from 0 through 8. Every mode is lossless; a higher level changes encoding time and file size, not audio quality. Controls that do not apply are disabled.

Updates

The add-on can check the official GitHub releases when NVDA starts. Automatic checks can be disabled in settings, and a manual check is available from Tools and Input Gestures. No personal data is sent.

A downloaded package is checked for size, SHA-256 when GitHub provides it, ZIP integrity, safe paths, add-on name, and version. The verified file is then handed to NVDA's normal installer, which still asks for confirmation and restart.

Custom keyboard shortcuts

Open NVDA menu, Preferences, Input Gestures, then find the “Easy Audio Converter” category. Custom gestures can be assigned to:

  • open settings;
  • convert the current selection with one-time options;
  • quickly convert the current selection;
  • convert the current folder;
  • show information about the selected audio file;
  • cycle the target format;
  • cycle quality;
  • choose the destination folder;
  • open advanced codec settings;
  • show the progress window;
  • show the latest conversion results;
  • report status;
  • cancel conversion;
  • stop after the current file;
  • report and clear the conversion queue;
  • check for updates;
  • open the support page.

Supported output formats

Encoding targets are MP3, WAV, FLAC, Ogg Vorbis, Opus, M4A/AAC, AAC, WMA, ALAC, AIFF, AC-3, E-AC-3, WavPack, MP2, AMR narrowband, and AMR wideband. Two additional targets extract the original audio stream or remux AAC to M4A without re-encoding.

For MP3, LAME and the Windows Media Foundation MP3 encoder can be selected. The latter is shown as the Fraunhofer/Windows option.

Notes

  • Additional jobs use the safe queue by default; the busy-job policy can run them in separate progress windows, while files within each job may also run in parallel.
  • Folder jobs require plan approval or confirmation before they start.
  • WAV inputs may use either the .wav or .wave extension.
  • Video containers are accepted when they contain a readable audio track.
  • Stream-copy modes always use the first readable audio stream.
  • Encrypted or copy-protected media cannot be converted.
  • Advanced parameters unsupported by a format are ignored or disabled.
  • Results retain details for up to 500 skipped files and the complete skipped count.
  • Common FFmpeg and filesystem failures are explained in the results window.
