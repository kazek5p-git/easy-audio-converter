# Easy Audio Converter 1.2.0

- Combined standard and advanced options into one Easy Audio Converter
  category in NVDA Settings, with two accessible tabs and direct Tools-menu
  commands for each tab.
- Added the successful-conversion sound originally prepared for the
  unreleased 1.1.3 development build; 1.2.0 makes its use configurable.
- Added “Convert selected files or folders with options” while retaining the
  existing immediate quick-conversion command.
- Added complete one-time job settings and named profiles. Built-in profiles
  cover Audiobook MP3, Podcast Opus, and Archive FLAC; custom profiles can be
  saved, replaced, and deleted.
- Added a modeless results window with success, failure, and skipped rows,
  detailed explanations, clipboard reports, output-folder access, and retry
  of only failed sources using their original job settings.
- Added configurable successful-completion modes: speech and sound, speech
  only, sound only, or none, plus a test-sound button.
- Added milestone, every-file, and on-demand progress announcement modes.
- Added estimated remaining time to the visual progress window and spoken
  status command.
- Added safe, bounded persistence for complete profiles and skipped-file
  details, along with expanded unit and package validation.

The options dialog, unified two-tab settings category, profile controls,
progress window, results window, mixed success/failure/skip job, repaired-file
retry, Polish speech output, and completion sound were tested with NVDA
2026.2 beta 8.

Version 1.1.3 was not published separately, so this release contains all of
its changes for users upgrading from the public 1.1.2 release.
