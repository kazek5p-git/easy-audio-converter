# Easy Audio Converter 1.1.0

- Added accessible current-file and whole-batch progress reporting.
- Added copying of all metadata, selected metadata fields, or no metadata.
- Added validated per-codec advanced profiles for bitrate, sample rate,
  channels, codec level, and PCM bit depth.
- Added secure update checks and package downloads from GitHub Releases.
- Added Poedit-compatible POT, PO, and MO translation catalogs.
- Expanded English and Polish help, architecture, testing, and translation
  documentation.
- Hardened cancellation, partial-file cleanup, metadata parsing, package
  verification, and error handling.

The add-on bundles a full FFmpeg build and works without a separate FFmpeg
installation.
