# Easy Audio Converter 1.1.1

- Metadata fields are now individual accessible check boxes whose states are
  spoken correctly by NVDA.
- Visual progress no longer floods speech with alternating percentages during
  batch jobs.
- The progress window now includes a “Report conversion status” button.
- Spoken status uses the newest worker progress snapshot.
- Focus behavior was improved when a job opens, is canceled, or completes.
- The Polish completion summary was corrected.

This maintenance release was validated interactively with NVDA Speech Viewer,
including settings, Explorer selection, progress, cancellation, error dialogs,
updates, and the support page.
